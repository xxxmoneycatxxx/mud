### 2. 门派相克系统

新增 `family_restrain()` 函数，定义门派间克制关系：

```
克制方：命中 +20%，伤害 ×1.5
被克方：命中 -20%，伤害 ×0.67
```

**收益**：增加 PVP 策略性，门派选择更有意义。

### 4. 动态奖励基数系统

任务奖励基数根据日期自动调整：

| 日期类型 | 基数 |
|----------|------|
| 元旦/国庆 | 400% |
| 春节/劳动节/端午 | 300% |
| 妇女节/儿童节/教师节 | 200% |
| 周末 | 150% |
| 普通日 | 100% |

管理员可临时调整（50%-500%），全服广播基数变化。

**收益**：增加节日活跃度，营造运营氛围。

---

### 5. 新增多样化任务类型

> **调研结论**：游戏已有 8 种系统任务模板 + 12 个江湖任务定义，任务类型比预期丰富。

**现有任务类型盘点**：

| 系统 | 已有类型 | 文件 |
|------|---------|------|
| 师门任务 | 追杀(capture)、运送(deliver)、搜寻(explore/search)、收集(supply)、纠纷(judge)、善恶(shen) | `clone/quest/*.c` |
| 天书任务 | 杀敌(kill)、寻物(find)、送信(song)、保护(baohu) | `cmds/usr/tianshu.c` |
| 江湖任务 | 击杀(getKill)、收集(getItem)、自定义条件(postCondition) | `adm/daemons/quest/*.c` |

**真正缺失/可增强的方向**：

| 方向 | 现状 | 改进内容 |
|------|------|----------|
| 守城/防守任务 | 完全空白 | 限时防守区域 + 波次进攻，全新机制 |
| 押镖增强 | deliver 已有运送，但无途中风险 | 加“途中劫匪”随机事件，变纯跑腿为有挑战的护送 |
| 限时杀手 | capture/shen 已有击杀，但无倒计时 | 加限时机制，增加紧迫感 |
| 新增江湖任务 | 框架成熟，仅 12 个定义 | 写新任务定义文件即可扩展（每种 ~160 行） |

每种新任务统一接入 `jobs` 追踪系统（已完成）。

**收益**：丰富日常玩法，减少重复感。

## 三、P1 — 中优先级（提升游戏深度）

### 6. 等级压制机制

`check_level()` 三级判定：
- 高等级对低等级有命中/伤害优势
- 适合副本 NPC 和 PVP 平衡

**收益**：等级差距有实际意义，激励玩家成长。

---

### 7. 新人保护

低等级玩家（<40级）战斗加成：
- AP 三倍加成
- 减少被高等级 NPC 秒杀的概率

**收益**：降低新手挫败感。

---

### 8. fly 轻功飞行

新增 `fly` 命令，轻功高手可御风飞行快速传送：

```
指令格式：fly [目的地]
条件：轻功技能 ≥ 100
消耗：内力（按距离计算）
可用目的地：扬州 长安 洛阳 北京 大理 开封 ...
```

**与 rideto 互补**：

| 对比 | rideto（骑马） | fly（轻功） |
|------|---------------|------------|
| 条件 | 需要坐骑 | 需要轻功修为 |
| 消耗 | 无 | 内力 |
| 风味 | 江湖行路 | 武林高手飞檐走壁 |

**架构基础**：11 个轻功技能已预留 `valid_enable("move")`，可直接复用。

**收益**：轻功有实战外用途，减少跑图时间，契合金庸世界观。

---

### 9. 经脉修炼系统

渐进式经脉打通，作为 `breakup`（任督二脉）的前置成长：

```
指令格式：jingmai [修炼|查看]
经脉列表：任脉、督脉、冲脉、带脉、阴维、阳维...
每条经脉提供不同加成（气血恢复、内力上限、疗伤效率等）
全部打通后可触发 breakup
```

**与现有体系衔接**：

```
锻炼经脉 → 打通任督二脉(breakup) → 元婴出世(animaout) → 生死玄关(death)
```

**收益**：breakup 前有成长目标，经脉体系更完整，契合金庸世界观。

---

### 10. NPC 动态行为密度提升（内容打磨）

> **性质**：内容调整，非功能开发。基础设施已完整。

- 提高重要 NPC 的 `chat_chance`（当前多为 1-5%）
- 在 chat_msg 中嵌入函数调用（喝酒、练剑、走动）
- 战斗聊天概率与等级挂钩

**收益**：世界更有活力，NPC 更有生命感。可随时穿插进行，无需专门排期。

---

### 11. 任务物品动态描述（可选）

> **性质**：锦上添花。建议仅为关键剧情物品添加。

对任务相关物品覆盖 `long()` 函数，根据任务状态显示不同描述：

```lpc
string long() {
    if (query("quest_target") == this_player()->query("id"))
        return "这是" + query("quest_giver") + "托你送来的密信。\n";
    return "一封密封的密信。\n";
}
```

**收益**：增强任务沉浸感。优先级较低，可合并到任务系统重构时一并处理。

## 四、P2 — 低优先级（锦上添花）

### 13. 身体部位权重

不同部位有不同伤害权重，增加战斗策略性：

```
头部: 100  颈部: 90   胸口: 90   后心: 80
左肩: 50   右肩: 55   左臂: 30   右臂: 30
小腹: 70   左腿: 40   右腿: 40
要害部位：头部、颈部、胸口、后心、小腹
```

**现状**：`limbs` 仅用于随机选择显示部位，无实际权重计算。

### 14. 门派特色战斗消息

击杀消息按门派分组，每个门派有独特招式名称：

```
14个门派 × 10-30个招式 = 140-420条消息
示例：少林「般若掌」「千手如来掌」/ 武当「太极拳」「绕指柔剑」
```

### 15. 反弹伤害体系

完整的 `on_hit()` 反弹函数 + 门派特色反弹描述：

```
on_hit() 函数框架：
- 物理伤害反弹百分比
- 法术伤害反弹百分比
- 门派特色反弹消息（每个门派独特描述）
```

**现状**：`damage_msg.h` 有反弹消息模板，但无 `on_hit()` 函数。

### 16. protect 保护命令

新增 `protect <玩家>` 命令，战斗中保护同房间的其他玩家：

```
机制：
- 保护者在被保护者被攻击时有概率自动加入战斗
- 消耗内力维持保护状态
- 同房间限制
```

### 17. 配偶技能共享

允许配偶间互相学习技能，增加婚姻系统实用价值：

```
实现：learn.c 中增加 couple_ob 检查
if (ob->query("couple/id") == me->query("id"))
    return 1; // 允许学习
```

**现状**：婚姻系统完整（订婚/离婚/证人），但配偶无特殊互动。

### 18. NPC 好感度系统

为重要 NPC 增加好感度机制，赠物提升好感，达到阈值触发特殊对话/赠物/教学：

```
int accept_object(object who, object ob)
{
    if (ob->query("liquid/type") == "alcohol") {
        who->add_temp("favor/" + query("id"), 1);
        // 好感度达到阈值触发特殊对话/赠物/教学
    }
}
```

**现状**：NPC 交互主要靠 inquiry 关键词触发。

### 19. 守护进程子目录模块化

将 combatd.c（2296行）等拆分为子目录模块化结构。
